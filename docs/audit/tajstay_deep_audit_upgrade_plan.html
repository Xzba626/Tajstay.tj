SQLite в продакшне — база не масштабируется
Критично
Prisma настроена на SQLite (schema.prisma: provider = "sqlite"). При 1 000+ одновременных запросов базы данных SQLite блокирует запись, а файл dev.db лежит прямо в /prisma. Для 1 млн пользователей это сразу упадёт.
Решение: Мигрировать на PostgreSQL + Prisma Accelerate (connection pooling). Добавить PgBouncer или Neon serverless.
Файлы загружаются в /public/uploads — не для продакшна
Критично
Фото отелей и номеров сохраняются в public/uploads/hotel-covers/ и /room-photos/. При деплое через Docker/Vercel это папка пересоздаётся, все фото теряются. Хранение статики на диске не масштабируется.
Решение: Cloudflare R2 или AWS S3 + CloudFront CDN. Размер фото 343KB — нет оптимизации, нужен Sharp/WebP pipeline.
Аутентификация — .env содержит реальные секреты
Критично
Файл .env включён в ZIP-архив с паролями, JWT secret, API ключами. В .gitignore он есть, но в репозиторий попадал судя по git history. NEXTAUTH_SECRET хранится в незашифрованном виде.
Решение: Rotate все секреты немедленно. Использовать Vault/Doppler/Railway Secrets. Rate limiting на auth endpoints (сейчас нет).
